# Arabic (Noto Sans Arabic) (language font pack, v1)

- Files: NotoSansArabic-Bold.ttf, NotoSansArabic-Regular.ttf, copied unchanged from github.com/notofonts/notofonts.github.io (fonts/NotoSansArabic/hinted/ttf), main branch as of 2026-10-24. Checksums are in manifest.json and match the Slopographic font pack list.
- Covers: Arabic, Persian, Urdu and other languages written in Arabic script.
- Licence: SIL Open Font License 1.1 (OFL.txt in this folder). Copyright the Noto Project Authors.
- Used by Slopographic apps to write text in this script (into PDFs and other files), downloaded only when it is needed or chosen in Get more.
