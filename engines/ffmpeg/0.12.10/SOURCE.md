# ffmpeg core 0.12.10 (FFmpeg compiled to WebAssembly)

- Files: `ffmpeg-core.js` and `ffmpeg-core.wasm`, copied unchanged from the npm package `@ffmpeg/core@0.12.10` (`dist/esm`).
- Licence: GPL-2.0-or-later (this build includes GPL components, such as x264). The licence text is in `LICENSE-GPL-2.0.txt`.
- Corresponding source:
  - The build scripts and the wrapper: https://github.com/ffmpegwasm/ffmpeg.wasm (the `packages/core` directory of the release that matches `@ffmpeg/core@0.12.10`).
  - The FFmpeg source it was built from: https://ffmpeg.org/download.html and https://github.com/FFmpeg/FFmpeg
  - The npm package: https://www.npmjs.com/package/@ffmpeg/core/v/0.12.10
- Checksums are in `manifest.json`. The apps check the SHA-256 before running the file.
