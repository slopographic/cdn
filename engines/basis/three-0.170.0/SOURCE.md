# Basis Universal transcoder (from three.js 0.170.0)

- Files: `basis_transcoder.js` and `basis_transcoder.wasm`, copied unchanged from the npm package `three@0.170.0` (`examples/jsm/libs/basis/`).
- What it is: the Basis Universal transcoder, used by three.js `KTX2Loader` when a glTF or GLB file has KTX2 textures (`KHR_texture_basisu`).
- Licence: Apache-2.0. The licence text is in `LICENSE-Apache-2.0.txt`.
- Source: https://github.com/BinomialLLC/basis_universal, and https://www.npmjs.com/package/three/v/0.170.0
- Checksums are in `manifest.json`. The apps check the SHA-256 before running the file.
