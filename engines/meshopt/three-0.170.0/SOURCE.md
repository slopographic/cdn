# meshoptimizer decoder 0.18 (from three.js 0.170.0)

- File: `meshopt_decoder.module.js`, copied unchanged from the npm package `three@0.170.0` (`examples/jsm/libs/meshopt_decoder.module.js`). It holds the WebAssembly decoder inline.
- What it is: the meshoptimizer decoder for the glTF extension `EXT_meshopt_compression`, used by three.js `GLTFLoader.setMeshoptDecoder`.
